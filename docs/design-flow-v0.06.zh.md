# 公开阶段 0.06 设计流程

这轮设计流程采用 evidence-first，也就是先证据、再传播：

1. 说明一个窄痛点。
2. 展示架构模式。
3. 运行诊断。
4. 解释 benchmark 结果。
5. 运行 privacy guard。
6. 发布安全的素材包。

## 本地能力映射

| 能力 | 本地是否可用 | 在本项目中的用途 |
| --- | --- | --- |
| Image generation skill | 可用，适合位图资产 | 已有 Image2 封面图和产品说明图。 |
| 仓库内 SVG 编辑 | 可用 | 架构图、运行逻辑图、benchmark 图、产品图。 |
| Browser Use 插件 | 可用 | 需要时可预览渲染后的文档或本地页面。 |
| Documents / Presentations 插件 | 可用 | 后续可把发布故事转成文档或幻灯片。 |
| Canva MCP | 当前主要是文档/设计指南能力 | 可用于设计指导，不作为发布素材包生成器。 |
| local-tools MCP | 可用 | 文件/Python 辅助能力，本身不是公开内容。 |

## 设计原则

- 技术证据优先使用确定性的 SVG 图。
- 位图资产只在比图示更能传达产品感时使用。
- 所有公开表述保持边界。
- 每个公开产物都必须通过隐私扫描。
- 中英文材料保持同步。

## 本阶段交付物

- 短演示脚本。
- 发布素材包。
- 设计流程文档。
- 更新 README 和发布路线图。

## 验收标准

- 用户可以按脚本直接录短演示。
- 用户可以从发布素材包直接复制发布文案。
- 所有材料避免私有路径、token、账号 ID 和路由细节。
- CI 仍然运行测试、audit 和 privacy guard。
