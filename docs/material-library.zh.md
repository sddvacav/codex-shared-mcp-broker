# 素材库

公开阶段：`0.08`

这个素材库是合法、许可感知的公开资源索引。

它不是第三方品牌资产的搬运仓库。除非明确允许再分发，否则不会把别人的专有 logo、宣传视频、产品截图、UI kit 或模板复制进本仓库。

## 为什么要有这个边界

充分利用公开资源是正确的。未经许可重新发布别人的受保护资产是不正确的。有效策略是：

1. 建立官方来源索引。
2. 记录使用边界。
3. 用这些来源做设计分析和灵感参考。
4. 从中提炼规律，制作自己的原创项目素材。
5. 仓库里只存放允许使用或自己创建的素材。

## 实际用途

用它回答：

- 应该研究哪个设计系统？
- 哪些品牌资产可以用？
- 哪些东西不能复制？
- 哪些内容可以转化成我们自己的原创素材？
- 哪些来源足够官方，适合引用？

## 规则

一切都可以成为项目的启发，但不是一切都能被复制进项目。
