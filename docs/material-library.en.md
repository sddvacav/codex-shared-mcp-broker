# Material Library

Public stage: `0.08`

The material library is a legal, license-aware index of public references.

It is not a dump of third-party brand assets. It does not copy proprietary logos, campaign videos, product screenshots, UI kits, or templates into this repository unless redistribution is clearly allowed.

## Why This Boundary Matters

Using public resources aggressively is correct. Republishing someone else's protected assets without permission is not. The useful strategy is:

1. Build a local index of official sources.
2. Record usage boundaries.
3. Use the sources for design analysis and inspiration.
4. Create original project assets from those lessons.
5. Store only allowed or self-created assets in the repository.

## Practical Use

Use the library to answer:

- What design system should we study?
- What brand assets are allowed?
- What must not be copied?
- What can be transformed into our own original asset?
- Which sources are official enough to cite?

## Rule

Everything can inform the project. Not everything can be copied into the project.
