Deployment boundary

GitHub Pages is for the static launch surface.

This page is static: HTML, CSS, images, and video. It does not run a backend, database, job queue, authentication, location service, or model inference.

Good fit: project landing page, docs, launch video, release assets.

Not enough for: full material-intelligence platforms, user accounts, database-backed workflows, paid APIs, location services, or compute-heavy jobs.

Business chain: GitHub Pages for awareness, app backend for product value, cloud infra for paid execution.
